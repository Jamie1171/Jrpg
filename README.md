# Jrpg

A story-led, turn-based JRPG project in pre-production, designed around a mobile playtesting workflow and a zero additional development-spend target.

Start with [Android JRPG research and story foundations](docs/research/android-jrpg-market-and-story-foundations.md).

The research compares 13 Android JRPGs and two adjacent crafting games, records 45 public Google Play review observations, and proposes original story and gameplay directions. The proposed title, cast, setting and mechanics are discussion drafts.

No playable game or build pipeline has been implemented yet.
