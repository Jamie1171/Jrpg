## Fields for each adopted solution

Record source URL, pinned version/commit, role (offline tool/runtime dependency/asset), code and asset licences, required notices, dependency list, local paths, modifications, verification results, known limitations, and update/removal approach. For generated assets also record preset, seed, source references, export settings and relationship to derived files. Never put credentials here.
