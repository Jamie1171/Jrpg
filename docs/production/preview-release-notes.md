# Brackenford 0.2.2 — first Meshy asset trial

Adds the prepared iron ore outcrop outside the inn and beside the woodland approach. This is a visual/collision trial; mining is not implemented yet.

The original 112,658-triangle model is reduced to 6,000 triangles, with softer pale markings and a 1K colour texture. The runtime model is approximately 280 KB. Some close-up painted stretching remains for later review.

Touch and Xbox controls remain available. Install as an update to keep your local save.

Ore generated by Jamie with Meshy, CC BY 4.0; adapted in Blender. See repository attribution and the in-game credits.
